# Hook bank (from Namrata, 25 Nov 2026)

Use these hooks and formulas as starting points. A hook may be adapted to 5 to 7 spoken words for the 0 to 2 second window; the on-screen line can carry the longer version.

Rules before using any hook here:
- The Reel's claim must be backed by research per the source guide in RUNBOOK.md. A hook that sounds true is not evidence.
- Many hooks here are advice or opinion ("Quitting is not failure", "Say this instead"). Present them as one evidence-informed approach, not a rule, and only where research supports the underlying mechanism.
- Never diagnose viewers or partners ("anxious", "avoidant", "narcissistic", "toxic"). Use "a pattern", "one possible explanation", "a tendency".
- See "Sensitive topics" in RUNBOOK.md for themes that must be held for Namrata's review.
